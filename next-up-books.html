Big Book API ALWAYS CONNECTED

Books uses Big Book API, routed through a small proxy — no account or API key needed on this device. Spins pull live book lists by decade + genre, with covers, ratings, and (when a title is picked) a link to its Open Library or WorldCat page. If "Always use built-in list" is selected below, or if the service can't be reached, the app falls back to its built-in curated list.

API Call Log

About

Next Up is a free, independent project — not affiliated with, endorsed by, or sponsored by Big Book API, Open Library, or any publisher. Book data, covers, and ratings come from Big Book API and are provided as-is; accuracy isn't guaranteed. No ads, no analytics or tracking of any kind.

IGDB ALWAYS CONNECTED

Games uses IGDB, routed through a small proxy — no account or API key needed on this device, but you do need to be signed in with Google to actually use it. Spins pull live game lists by platform + genre, with covers, ratings, and (when a title is picked) a search link to look it up further. If not signed in, "Always use built-in list" is selected below, or the service can't be reached, the app falls back to its built-in curated list.

Data Source

Max Results

How many titles you'll see after a IGDB spin (10–100). If filtering leaves you short, it fetches more to make up the difference — higher numbers mean a longer wait. Doesn't affect the built-in list.

API Call Log

Every IGDB request made since your last spin, and why — useful for seeing where time (and today's free-tier quota) goes. Clears on the next spin.

About

Next Up is a free, independent project — not affiliated with, endorsed by, or sponsored by IGDB, Twitch, or any publisher. Game data, covers, and ratings come from IGDB and are provided as-is; accuracy isn't guaranteed. No ads, no analytics or tracking of any kind.
